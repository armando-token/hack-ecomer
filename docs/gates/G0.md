   - *Resolution for G1:* Use `npm` with `--prefix b2b-storefront` using the existing `package-lock.json` or enable Yarn via `corepack enable`.

4. **Python ReportLab Dependency Missing:**
   - *Observation:* `python3` lacks `reportlab`.
   - *Resolution for G1:* Install `reportlab` via pip in G1 to support quote PDF rendering.
