## 1. Objective and Mandate

Gate G5 transitions the Controlnautas evaluation system from legacy boolean heuristics into an industrially strict, 100% deterministic pure evaluation engine:
1. **Zero False Positives:** Eliminate all known false positive modes:
   - Missing property + `not_equals` must never evaluate to `meets`.
   - Inverse range coverage (Condition B) must never evaluate to `meets`.
   - Unit mismatches (e.g. 20 A vs 20 mA) must never evaluate to `meets`.
   - Electrical nature mismatches (VAC vs VDC) must never evaluate to `meets`.
   - Physical interface without documented protocol (RS-485 without Modbus) must never evaluate to `meets`.
   - Family options without variant proof must never evaluate to `meets`.
   - Empty requirements array must return `not_documented` with `NO_REQUIREMENTS`.
2. **Pure Evaluator Core:** Zero external I/O (no HTTP, no database queries inside core). Closed tri-state verdict system: `meets`, `does_not_meet`, `not_documented`.
3. **Heating Chamber Pilot Circuit Rules:** Enforce electrical, signal, and topological consistency across the Heating Chamber sensor $\rightarrow$ controller $\rightarrow$ power actuator $\rightarrow$ heater load path.
4. **Deterministic Bipartite Matching:** Allocate channels and ports reproducibly without over-subscription or multifunction mode conflicts; verify RS-485/Modbus address uniqueness and baud/parity intersections.
5. **V1 Route Invariance:** Preserve all existing response fields and boolean types for `/api/muse/v1/evaluate` while augmenting with v2 tri-state detail fields (`overall_verdict`, `verdict`, `reason_code`, `evidence_refs`, `rule_set_version`, `unverified_scopes`).
6. **Zero Fabricated SKUs & No LLM in Evaluation Path:** Ensure all evidence references anchor to real manufacturer datasheets, with unverified scopes remaining explicitly `not_documented`.
