## 1. Objective and Mandate

1. Create a synthetic GLB (`SYN-IND-CTRL-01.glb`) with verified dimensions in **METERS**, right-handed coordinate frame (`+Y up, +Z front`), explicit attachment anchors, PBR materials, and SHA-256 content addressing.
2. Produce an asset manifest JSON declaring `units: "meter"`, `bbox`, `anchors`, `fidelity: "synthetic_dimensional_proxy"`, and cryptographic byte lengths.
3. Deploy an experimental delivery surface in the Medusa backend supporting:
   - Content-addressed binary delivery: `/industrial-assets/{sha256}/{filename}` and `/api/industrial/v2/experimental/assets/{sha256}/{filename}`
   - Metadata and manifest resolution: `/api/industrial/v2/experimental/assets/{assetId}`
   - Signed/tokenized URL downloads with expiration: `/api/muse/v1/experimental/assets/{assetId}/download?token=...&expires=...`
   - Headers: `Content-Type: model/gltf-binary`, `Cache-Control: public, max-age=31536000, immutable`, ETag, Range requests, and wildcard CORS (`Access-Control-Allow-Origin: *` without credentials).
4. Verify endpoints locally with `curl` (HEAD, GET, byte match, expired token rejection, invalid token rejection).
5. Prepare an OpenAPI 3.1 snippet, an operator checklist for the human operator with Muse credentials, and document external observability limitations.

## 5. Architectural Boundaries & Observability Limitations

Per MEGAPLAN §16 and §25:
1. **No Iframe Assumption:** Controlnautas delivers JSON and 3D binary assets to Meta Muse. We make no assumption that Meta Muse embeds as an iframe inside the Controlnautas storefront.
2. **Client-Side Rendering in Muse:** 3D rendering occurs inside Meta Muse's runtime / client application.
3. **Scene Graph Hash Observability:** Inspection of Meta Muse's internal scene graph hash or visual framebuffer is `not_observable` from this server without Meta Muse client telemetry. Verification relies on asking the operator to inspect the model in Muse.
4. **HTTPS Production Host:** Public host `data.controlnautas.com` is configured to Elastic IP `54.84.170.82`. If external HTTPS is pending certificate configuration, the staging HTTP path (`http://127.0.0.1:9000/...`) provides identical bit-level fidelity.
